# QQbox

AstrBot QQ 聊天气泡生成插件，支持文字、图片和 GIF 气泡。

- 当前版本：`v1.4.13`
- AstrBot：`>= 4.26.3`
- 平台：QQ（aiocqhttp）

## 功能

- 生成文字、图片和 GIF 聊天气泡。
- 自动获取 QQ 昵称和头像。
- 设置用户备注名、头衔和头衔颜色。
- 在插件页面调整头像、头衔、昵称和气泡样式。
- 保存多套布局并选择当前使用的布局。
- 在插件页面管理已保存的用户资料。
- 字体缺失时自动下载并保存在 AstrBot 持久化目录。

## 安装

1. 在 AstrBot 中安装 QQbox 插件。
2. 重启或重载插件。
3. 首次启动时等待字体下载完成。
4. 使用 `/qb font status` 查看字体状态。

字体下载会继承 AstrBot 的全局网络代理。GitHub 直连失败时，插件会自动切换 AstrBot 内置镜像，无需重复配置。

字体尚在下载时，文字、图片和 GIF 生图命令会立即返回当前下载进度，不会一直等待。

## 命令

所有命令以 `/qb` 开头。

| 命令 | 说明 | 示例 |
|---|---|---|
| `/qb echo QQ号 内容` | 生成文字气泡 | `/qb echo 123456789 大家好` |
| `/qb img QQ号` | 将消息或回复中的图片生成气泡 | `/qb img 123456789` |
| `/qb gif QQ号` | 将消息或回复中的 GIF 生成气泡 | `/qb gif 123456789` |
| `/qb sn QQ号 备注名` | 设置显示名称 | `/qb sn 123456789 艾玛` |
| `/qb st QQ号 头衔` | 设置头衔 | `/qb st 123456789 传奇扫雷王` |
| `/qb sc QQ号 颜色编号` | 设置头衔颜色，范围 `1-4` | `/qb sc 123456789 4` |
| `/qb ua QQ号` | 重新获取昵称和头像 | `/qb ua 123456789` |
| `/qb font status` | 查看字体状态 | `/qb font status` |
| `/qb font retry` | 重新尝试下载字体 | `/qb font retry` |
| `/qb help` | 查看命令帮助 | `/qb help` |

使用图片或 GIF 命令时，可以：

- 在包含图片的消息中发送命令。
- 回复一条图片消息后发送命令。

头衔颜色编号：

| 编号 | 颜色 |
|---|---|
| `1` | 灰色 |
| `2` | 紫色 |
| `3` | 黄色 |
| `4` | 绿色 |

## 插件页面

在 AstrBot 的 QQbox 插件详情页打开管理页面。

### 气泡调节

- 修改头像、头衔、昵称和气泡的位置。
- 调整字体、字号、颜色、圆角和宽度。
- 直接拖动预览中的元素。
- 新建、保存、启用、停用、重置或删除布局。

保存布局后，点击“设为当前”才会用于聊天命令。停用布局后恢复插件默认样式。

### 数据库管理

- 搜索用户。
- 修改用户名称、头衔和颜色。
- 新增或删除用户资料。

## 配置

AstrBot 配置页只保留字体下载设置。

| 配置项 | 说明 | 默认值 |
|---|---|---|
| `font_download.auto_download` | 字体缺失时自动下载 | `true` |

插件会使用 AstrBot 的全局网络代理。字体、字号、颜色和布局请在插件页面中设置。

## 数据保存

以下数据保存在 AstrBot 的 QQbox 插件持久化目录中，更新插件不会删除：

- `db/qqbox.db`：用户资料和布局。
- `avatars/`：头像缓存。
- `fonts/`：下载的字体。

## 常见问题

### 提示字体尚未准备完成

1. 发送 `/qb font status` 查看状态。
2. 检查 AstrBot 的全局网络代理。
3. 发送 `/qb font retry` 重新下载。

### 图片或 GIF 命令没有找到图片

请在带图片的消息中发送命令，或回复原图片后再发送命令。

### 修改布局后没有生效

保存布局后，点击插件页面中的“设为当前”。

### 昵称或头像不正确

发送 `/qb ua QQ号` 重新获取，也可以在“数据库管理”中直接修改名称。
